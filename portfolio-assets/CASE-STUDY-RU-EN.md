## RU — для резюме, соцсетей, презентаций

**ИИ-Гараж: сайт-экосистема с нуля до продакшена — ai-garage.tech**

Каталог из 16 ИИ-кейсов, SEO-блог с браузерной админкой, аналитика и продающий копирайт. Весь цикл выполнен одним специалистом с ИИ-инструментами, инфраструктура — $0/мес.

**Что сделано:**
- Авторская дизайн-система «Blueprint Seam»: чертёжная сетка, собственный пиксель-арт роботов (SVG), RU/EN
- Сайт-каталог: 16 кейсов, фильтры, карусель, мобильная адаптация
- Блог на Astro с CI/CD: от «Publish» до живой статьи ~2 минуты, автоматически
- CMS без бэкенда: Decap + GitHub OAuth через serverless-прокси на Cloudflare Workers
- SEO: автогенерация sitemap, canonical, og-теги + 4 статьи под реальные поисковые запросы
- Аналитика Microsoft Clarity с отслеживанием конверсии (клики в Telegram)
- Домен, DNS, принудительный HTTPS, 301-редиректы
- Продающий копирайт: манифест, секция «боль → решение», строки результата в кейсах

**Результат:** работающая воронка «поиск → статья → кейсы → заявка в Telegram» при нулевой стоимости владения. 100% статика — нет сервера, нечего взламывать.

**Стек:** HTML/CSS/JS, Astro, Decap CMS, GitHub Actions, GitHub Pages, Cloudflare Workers, Microsoft Clarity, DNS/HTTPS, SEO.

## EN — for Upwork profile / proposals

**AI Garage: a website ecosystem from zero to production — ai-garage.tech**

A catalog of 16 AI case studies, an SEO blog with a browser-based CMS, analytics, and conversion-driven copy. The entire cycle delivered solo using AI-assisted development. Infrastructure cost: $0/month.

**What I built:**
- Custom "Blueprint Seam" design system: blueprint grid, hand-made pixel-art robots (pure SVG), RU/EN language switcher
- Case catalog: 16 project cards with category filters, carousel, fully responsive
- Blog on Astro with CI/CD: from clicking "Publish" to a live article in ~2 minutes, fully automated
- CMS with no backend: Decap CMS + GitHub OAuth via a custom serverless proxy on Cloudflare Workers
- SEO foundation: auto-generated sitemap, canonical URLs, Open Graph tags + 4 guide articles targeting real search queries
- Microsoft Clarity analytics with conversion tracking (Telegram CTA clicks)
- Custom domain, DNS, enforced HTTPS, 301 redirects from the legacy address
- Conversion copywriting: benefit-driven manifesto, pain-to-solution section, outcome lines on every case card

**Outcome:** a working funnel — search → article → case studies → Telegram lead — at zero cost of ownership. 100% static: no server, nothing to hack.

**Stack:** HTML/CSS/JS, Astro, Decap CMS, GitHub Actions, GitHub Pages, Cloudflare Workers, Microsoft Clarity, DNS/HTTPS, SEO.

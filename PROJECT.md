## Технические факты

- Пайплайн блога: пуш в `blog-src/**` → Actions `build-blog.yml` (Node 22, concurrency guard) → собранный HTML коммитится в `blog/` + sitemap в корень → Pages публикует
- `.nojekyll` в корне обязателен (иначе Pages падает на `[...slug].astro`)
- Не пушить много коммитов подряд быстро — деплои Pages конфликтуют в очереди; лечение зависшего деплоя: пустой коммит-пуш
- OAuth для админки: GitHub OAuth App «ИИ-Гараж блог» + Cloudflare Worker `ii-garage-cms-auth.pixepop1.workers.dev` (код — sveltia-cms-auth; секреты в переменных воркера, в репо их НЕТ)
- og-image.png сгенерирован PIL-скриптом (стиль: слаты гаража + сетка); favicon.png/ico и логотип в шапке — вырезаны из значка «Ai» (кроп + морфологическая очистка альфа-канала от шума)
- `/about/` и `/privacy/` — обычный статический HTML в корне репо, НЕ часть Astro-сборки блога; при правке редактировать напрямую, `build-blog.yml` их не трогает
- Логотипы технологий в блоке «Работаем с» — настоящие SVG с CDN Simple Icons (`cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`), вставлены как inline `<path>`, не сторонние картинки
- Фото команды (`team-stas.jpg`, `team-uliana.jpg`) — кроп идентичным боксом (0.30, 0.11, 0.735, 0.855 от исходника) для одинаковой рамки; при замене фото сохранять те же пропорции, иначе карточки визуально разъедутся

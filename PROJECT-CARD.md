## Карточка для портфолио

**Название:** ИИ-Гараж / AI Garage — сайт-каталог ИИ-внедрений с блогом

**Роль:** Продумала архитектуру и полностью реализовала сайт от нуля — от визуального стиля и структуры кейсов до отдельной подсистемы блога с автоматической публикацией.

**Что сделано:**
- Сайт-каталог с 16 реальными кейсами ИИ-агентов и автоматизации, RU/EN переключение языка, фильтрация по категориям
- Авторский визуальный стиль «Blueprint Seam» (гараж + чертёжная сетка, тёмная палитра, моноширинный шрифт) — применён по всей странице: hero, разделители секций, карточки, футер
- Собственный пиксель-арт набор ИИ-агентов (SVG, без сторонних ассетов), включая анимацию сборки робота в hero
- Живая витрина реального AI-офиса компании (скриншот в стилизованной рамке-мониторе) вместо шаблонных плейсхолдеров команды
- **Блог на Astro** с автоматической сборкой через GitHub Actions — каждая статья это отдельная индексируемая HTML-страница (SEO из коробки: canonical URL, meta description)
- **Decap CMS** — веб-панель публикации без доступа к коду: настроена авторизация через GitHub OAuth и собственный serverless OAuth-прокси на Cloudflare Workers
- Хостинг — GitHub Pages, без бэкенда и базы данных, весь сайт статический

**Технологии:** HTML/CSS/JS (ванильный), Astro, Decap CMS, GitHub Actions, Cloudflare Workers, GitHub Pages

**Что показывает:** способность спроектировать и довести до продакшена не просто лендинг, а полноценную мини-инфраструктуру публикации контента — с нуля, включая CI/CD и авторизацию — без единого платного сервиса.
